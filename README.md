# queueing-monte-carlo-sim

排队论蒙特卡洛仿真 —— 物流配送中心装卸货位（装卸港）作业模拟。

以单服务台排队系统 **M/M/1** 为基础，用离散事件蒙特卡洛仿真模拟物流配送中心单个装卸货位上
100 辆货车的到达、排队、装卸全过程，统计**平均等待时间**、**货位空闲次数**、**系统最大排队
车辆数**三项指标，并进一步仿真 2 个、3 个货位的方案，给出货位扩容的量化依据。

课程设计《物流系统分析与设计》配套程序。报告全文见 [`docs/`](docs/)。

---

## 1. 模型与参数

| 参数 | 符号 | 取值 | 说明 |
|---|---|---|---|
| 货车到达速率 | λ | 15 辆/h | 到达间隔 ~ Exp(λ)，平均 4 min |
| 单货位服务速率 | μ | 20 辆/h | 装卸时长 ~ Exp(μ)，平均 3 min |
| 服务强度 | ρ = λ/μ | 0.75 | 系统稳定的前提 ρ < 1 |
| 货位数 | c | 1（另仿真 2、3） | 对比方案 |
| 单次仿真车辆数 | n | 100 辆 | 有限样本 |
| 独立重复次数 | REPS | 500 | 用于统计置信区间 |
| 基准随机种子 | seed | 20260101 | 保证结果可复现 |

主要理论指标（M/M/1 稳态）：`Lq = ρ²/(1−ρ) = 2.25 辆`，`Wq = Lq/λ = 9.00 min`，
`W = Wq + 1/μ = 12.00 min`，`P0 = 1 − ρ = 0.25`。

## 2. 环境与运行

```bash
# 仅需标准库即可完整运行
python sim_mmc.py                    # 500 次独立重复 + 敏感性分析 + 成本比较
python sim_mmc.py --reps 50          # 快速自检
python sim_mmc.py --rng numpy        # 用 numpy 加速（结果与默认模式逐位一致）
python sim_mmc.py --plot             # 额外输出 4 张结果图（需要 matplotlib）
python test_sim_mmc.py               # 运行自检用例（unittest，共 20 项）
```

`--rng python`（默认）与 `--rng numpy` 使用**同一递推式**的随机数发生器：前者是纯 Python
实现，后者是 numpy `uint32` 向量化实现，相同种子下两者输出的随机数序列逐位一致。
`tools/rng_spec.mjs` 用于验证该递推式的运算顺序，`tools/mirror_verify.mjs` 提供了完整的
独立复算程序。

## 3. 输出结果（seed = 20260101）

### 3.1 单次仿真的三项核心指标（c = 1）

| 指标 | 数值 | 说明 |
|---|---|---|
| 货车平均等待时间 | 6.00 min | 全部 100 辆货车 |
| 排队车辆平均等待时间 | 7.60 min | 79% 的货车需要排队 |
| 装卸货位空闲次数 | 21 次 | 含系统初始空闲 1 次 |
| 系统最大排队车辆数 | 7 辆 | 仿真全过程最大值 |
| 货位利用率 | 76.1% | 空闲时长 101.1 货位·min |
| 仿真总工期 | 423.5 min | 首车到达至末车离开 |

### 3.2 与 M/M/c 稳态理论值对照（各 500 次独立重复）

| 货位数 c | 理论 ρ | 理论 Wq/min | 仿真 Wq/min | 95% 置信区间/min | 仿真最大排队/辆 | 货位利用率 |
|---|---|---|---|---|---|---|
| 1 | 0.750 | 9.00 | 7.44 | [6.99, 7.90] | 8.53 | 72.7% |
| 2 | 0.375 | 0.49 | 0.46 | [0.43, 0.49] | 3.16 | 37.1% |
| 3 | 0.250 | 0.06 | 0.05 | [0.05, 0.06] | 1.65 | 24.8% |

单货位时仿真均值比理论值低约 17%，原因是系统在 t = 0 为空，前若干辆货车几乎无需等待，
"冷启动"阶段拉低了均值；c = 2、3 时误差缩小到 6% 左右。平均等待时间的标准差达
5.23 min（5% / 95% 分位数 2.43 / 19.39 min），说明**单次仿真结果波动很大，必须用多次
重复的均值与置信区间作为结论依据**。

### 3.3 到达率敏感性（c = 1，各 500 次重复）

| 到达率/(辆·h⁻¹) | ρ | 平均等待/min | 平均最大排队/辆 | 货位利用率 |
|---|---|---|---|---|
| 12.0 | 0.600 | 4.13 | 6.10 | 59.1% |
| 13.5 | 0.675 | 5.53 | 7.21 | 66.1% |
| 15.0 | 0.750 | 7.44 | 8.53 | 72.7% |
| 16.5 | 0.825 | 9.96 | 10.04 | 78.7% |
| 18.0 | 0.900 | 13.12 | 11.88 | 83.9% |

到达率仅提高 20%，平均等待时间就上升 76%，说明错峰调度对系统拥堵非常敏感。

### 3.4 方案成本比较

设货车等待成本 60 元/(辆·h)、货位运行成本 25 元/(货位·h)，以单次仿真周期（约 6.9 h）核算：

| 方案 | 等待成本/元 | 货位成本/元 | 总成本/元 | 折合每辆/元 |
|---|---|---|---|---|
| 1 个货位（现状） | 766.9 | 171.7 | 938.6 | 9.39 |
| **2 个货位（推荐）** | 46.5 | 337.1 | **383.6** | **3.84** |
| 3 个货位 | 5.5 | 505.4 | 510.9 | 5.11 |

增开第二个货位可使平均等待时间下降 93.8%，总成本下降 59.1%；第三个货位因闲置成本上升
反而不经济。

## 4. 修订说明（相对初版程序）

初版程序在附录代码中有三处实现错误，导致报告结果与代码不符：

1. **等待时间恒为负**：出队时先执行 `server_end_time = 0` 再计算 `wait = server_end_time - car_arr`，
   等价于 `-car_arr`，2000 次复算的平均等待时间为 −202 min；
2. **时间轴被清零**：同一处把货位完成时刻重置为 0，使"货位由忙转闲"的判断每次都成立，
   空闲次数退化为"处理的车辆数"（恒为 100 次）；
3. **空闲判定口径错误**：把"到达时货位恰好空闲"也计为一次空闲，与报告中"从忙碌转为
   空闲"的定义矛盾，且未计入系统初始的空闲状态。

修订版按报告第 3 章算法重写，并补充了多次独立重复、置信区间、理论值校验、敏感性分析与
成本比较；`test_sim_mmc.py` 中的时间轴自洽性、空闲次数手工算例等用例可防止此类错误再次出现。

## 7. 复现说明

两套随机数实现使用同一递推式，因此 `python sim_mmc.py` 的输出应当与本文档第 3 节一致。
若结果不同，请检查 Python 版本（建议 3.8+）并运行 `python test_sim_mmc.py` 定位问题。
`tools/mirror_verify.mjs`（Node.js）是与本程序逻辑等价的独立实现，可用于交叉复核：
两者的单次仿真指标与 500 次重复统计结果完全一致。
